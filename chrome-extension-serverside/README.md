# Gradescope AI Grader - Chrome Extension (Server-Side Version)

🤖 AI-powered homework grading for Gradescope - Server-side architecture for secure Chrome Web Store distribution

---

## 🏗️ Architecture

This is the **server-side version** that calls YOUR backend server instead of OpenAI directly.

```
User Browser → Extension → YOUR Server → OpenAI API
```

**Benefits:**
- ✅ Your OpenAI API key stays secure on your server
- ✅ Users can't extract or abuse your key
- ✅ You control access via user API keys
- ✅ Implement usage limits and subscriptions
- ✅ Update grading prompts without republishing extension

## 🚀 Quick Start

### For Users (Installing the Extension)

1. **Download the extension** from Chrome Web Store (after you publish it)
   - OR load unpacked for development

2. **Register for an API key:**
   - Click extension icon
   - Go to "Register/Login" tab
   - Enter email and password
   - Get your API key automatically

3. **Start Grading:**
   - Go to Gradescope grading page
   - Click "🤖 AI Grade All" button
   - Watch AI grade all submissions!

### For Developers (Setting Up)

1. **Deploy Backend Server First!**
   - See `../SERVER_DEPLOYMENT.md` for details
   - Deploy to Heroku, Render, Railway, etc.
   - Get your server URL: `https://your-server.com`

2. **Update Extension with Server URL:**
   ```javascript
   // Edit background.js line ~78
   serverUrl: 'https://your-deployed-server.com'
   ```

3. **Test Locally:**
   ```bash
   # Load extension
   1. Open chrome://extensions/
   2. Enable "Developer mode"
   3. Click "Load unpacked"
   4. Select this folder (chrome-extension-serverside)
   ```

4. **Test Registration:**
   - Click extension icon
   - Register a test account
   - Verify API key works
   - Test grading on Gradescope

5. **Publish to Chrome Web Store:**
   - See `../CHROME_WEB_STORE_GUIDE.md`

## 🔒 Security

### User API Keys
- Generated by YOUR server upon registration
- Format: `gs_[64 hex characters]`
- Stored in Chrome sync storage
- Required for all grading requests

### Server Communication
```javascript
POST https://your-server.com/api/grading/grade
Headers:
  X-API-Key: gs_user_key_here
  Content-Type: application/json
Body:
  {submissionData, rubricItems, question, ...}
```

### CORS
- Server only accepts requests from your extension ID
- Prevents unauthorized access

## 📊 User Flow

```
1. User installs extension from Chrome Web Store
2. User clicks extension icon → Register
3. Server creates account → Returns API key
4. Extension saves API key locally
5. User goes to Gradescope grading page
6. User clicks "AI Grade All" button
7. Extension extracts submission images
8. Extension sends to YOUR server with API key
9. Server validates key → Calls OpenAI
10. Server returns grading decision
11. Extension selects rubric item
12. Repeat for all students
```

## 📡 API Endpoints (Your Server)

### Authentication
```
POST /api/auth/register     - Register new user
POST /api/auth/login        - Login existing user
GET  /api/auth/verify       - Verify API key
GET  /api/auth/usage        - Get usage stats
```

### Grading
```
POST /api/grading/grade     - Grade submission (requires auth)
```

All endpoints require `X-API-Key` header (except register)


### Common Errors

**"Cannot connect to server"**
- Server is down or URL is wrong
- Check `serverUrl` in extension storage
- Verify server is running: `curl https://your-server.com/health`

**"Invalid API key"**
- User needs to register
- API key expired or deleted
- Check server logs for auth errors

**"Daily request limit exceeded"**
- Free tier limit reached (100/day)
- Upgrade to premium plan
- Or wait 24 hours
