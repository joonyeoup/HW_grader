ICON PLACEHOLDER

The extension requires icons in these sizes:
- icon16.png (16x16 pixels)
- icon48.png (48x48 pixels)
- icon128.png (128x128 pixels)

To create icons:
1. Use any image editor (Photoshop, GIMP, Figma, etc.)
2. Create a simple icon with the robot emoji 🤖 or "AI" text
3. Export in three sizes above
4. Place in this icons/ directory

OR use an online icon generator:
1. Go to https://www.favicon-generator.org/
2. Upload a square image or logo
3. Generate icons
4. Download and rename to icon16.png, icon48.png, icon128.png

For now, the extension will work without icons, but Chrome will show a warning.
You can temporarily use any PNG files renamed to these names.
